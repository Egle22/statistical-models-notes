# Statistical Models — Course Notes

About 300 pages of personal notes for the course *Statistical Models and Applications*
([University], [Lecturer], 2025). Each method is derived formally and then worked
through in R, with code and output.

📄 **[Read the notes (PDF)](Statistical-models-notes.pdf)**

## Contents
1. Gaussian linear model: ML and REML estimation, likelihood ratio and Wald tests, categorical regressors
2. Model selection: nested models, adjusted R², cross-validation, AIC and BIC
3. Gaussian linear mixed models: random intercept and slope, heteroscedastic and correlated errors, tests on fixed and random effects
4. Polynomial regression
5. Regression splines and P-splines: B-spline bases, knot selection, penalised likelihood
